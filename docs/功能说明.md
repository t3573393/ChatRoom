# ChatRoom 功能说明

## 1. 用户认证与房间管理

### 1.1 用户登录

**功能描述：** 用户通过用户名和房间代码登录系统

**流程：**
1. 用户输入用户名和房间代码
2. 点击登录按钮
3. 系统验证并跳转到聊天室

**相关文件：**
- `public/app/views/login.html` - 登录页面
- `public/app/controllers/loginController.js` - 登录控制器

### 1.2 房间管理功能

| 功能 | 描述 | 权限 | 相关代码 |
|------|------|------|----------|
| 创建房间 | 首个用户自动成为创建者 | 所有用户 | roomManager.js |
| 踢出用户 | 将用户移出房间 | 房间创建者 | roomManager.js |
| 禁言/解禁 | 禁止/恢复用户发言 | 房间创建者 | roomManager.js |
| 获取在线成员 | 查看房间当前在线用户 | 所有用户 | userManager.js |

## 2. 消息系统

### 2.1 消息类型

| 类型 | 描述 | 支持 | 文件类型 |
|------|------|------|----------|
| text | 文本消息 | ✓ | - |
| image | 图片 | ✓ | png, jpg, gif |
| music | 音频文件 | ✓ | mp3, wav |
| pdf | PDF文档 | ✓ | pdf |
| meme | 表情包 | ✓ | 图片格式 |
| gif | GIF动图 | ✓ | gif |
| code | 代码片段 | ✓ | - |

### 2.2 消息状态

| 状态 | 描述 | 图标 |
|------|------|------|
| sent | 已发送 | ✓ |
| delivered | 已送达 | ✓ |
| read | 已读 | 👁 |
| edited | 已编辑 | - |
| recalled | 已撤回 | - |

### 2.3 消息操作

| 操作 | 时间限制 | 描述 |
|------|----------|------|
| 编辑 | 5分钟内 | 可修改消息内容 |
| 撤回 | 10分钟内 | 删除消息，显示"消息已撤回" |
| 回复引用 | 无限制 | 引用回复某条消息 |
| @提及 | 无限制 | @username 提及用户 |
| 搜索 | 无限制 | 搜索历史消息 |

### 2.4 消息发送流程

```
用户输入内容
    ↓
前端输入验证
    ↓
敏感词过滤
    ↓
Socket.io 发送 send-message
    ↓
服务器保存到数据库
    ↓
广播 new message 给所有客户端
    ↓
更新发送者消息状态为 sent
```

## 3. 文件系统

### 3.1 文件上传

**支持的格式：**
- 图片：png, jpg, jpeg, gif
- 音频：mp3, wav
- 文档：pdf

**上传流程：**
```
用户选择文件
    ↓
前端验证（类型、大小）
    ↓
FormData 上传到 /v1/uploadImage 等
    ↓
后端 Formidable 解析
    ↓
保存到服务器文件系统 (public/upload/)
    ↓
记录到 files_array (内存)
    ↓
保存文件信息到数据库
    ↓
Socket.io 广播消息
```

### 3.2 文件预览

| 类型 | 预览方式 | 组件 |
|------|----------|------|
| 图片 | 直接显示 | `<img>` |
| PDF | PDF.js 在线预览 | `<pdf-viewer>` |
| 音频 | 自定义播放器 | `<audio-player>` |
| 其他 | 显示图标和下载链接 | - |

### 3.3 文件下载

**下载方式：**
- 点击下载按钮触发下载
- 直接下载（不通过 API）
- 支持文件名指定

### 3.4 文件过期清理

- 默认过期时间：8 小时
- 清理任务间隔：1 小时
- 过期后从文件系统和内存中删除

## 4. 阅后即焚

### 4.1 功能描述

发送阅后即焚消息，接收者查看后消息自动销毁。

### 4.2 流程

```
发送者开启阅后即焚模式
    ↓
发送消息（标记 isBurnAfterReading）
    ↓
接收者收到消息，启动倒计时
    ↓
倒计时结束（默认10秒）
    ↓
从 DOM 删除消息
    ↓
从数据库删除
    ↓
广播 message-burned 事件
    ↓
其他客户端同步删除
```

### 4.3 安全机制

- 销毁前检查消息是否已删除（幂等操作）
- 使用 destroyed/destroying 标志防止重复销毁
- 消息不存在时跳过销毁
