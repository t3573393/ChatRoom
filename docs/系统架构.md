# ChatRoom 系统架构

## 1. 系统概述

ChatRoom 是一个基于 Node.js 和 AngularJS 的实时聊天室应用，支持文本消息、图片、文件、音频分享，以及阅后即焚、消息编辑撤回等高级功能。

### 1.1 技术栈

| 层级 | 技术 |
|------|------|
| 后端 | Node.js, Express 4.x, Socket.io |
| 数据库 | SQLite3 |
| 前端 | AngularJS 1.4, Bootstrap 3, AdminLTE |
| 文件上传 | Formidable |
| 国际化 | angular-translate |
| 富文本编辑 | CKEditor, bootstrap-wysihtml5 |
| 图表 | Chart.js |

## 3. 前后端通信

### 3.1 HTTP REST API

| 方法 | 路径 | 描述 |
|------|------|------|
| POST | `/v1/uploadImage` | 上传图片 |
| POST | `/v1/uploadAudio` | 上传音频 |
| POST | `/v1/uploadPDF` | 上传文档 |
| POST | `/v1/getfile` | 获取文件信息 |
| GET | `/v1/messages/:roomCode` | 获取历史消息 |
| GET | `/api/export-chat` | 导出聊天记录 |
| POST | `/api/burn-message` | 销毁阅后即焚消息 |
| POST | `/api/edit-message` | 编辑消息 |
| POST | `/api/recall-message` | 撤回消息 |

### 3.2 WebSocket 事件

**客户端 → 服务器：**

| 事件 | 描述 |
|------|------|
| `join-room` | 用户加入房间 |
| `send-message` | 发送消息 |
| `user-writting` | 用户正在输入 |
| `user-stop-writting` | 用户停止输入 |
| `get-online-members` | 获取在线成员 |
| `mark-messages-read` | 标记消息已读 |
| `view-message` | 标记单条消息已读 |

**服务器 → 客户端：**

| 事件 | 描述 |
|------|------|
| `online-members` | 在线成员列表更新 |
| `new message` | 新消息 |
| `new message image` | 新图片消息 |
| `message-edited` | 消息已编辑 |
| `message-recalled` | 消息已撤回 |
| `message-delivered` | 消息已送达 |
| `message-read` | 消息已读 |
| `you-have-been-kicked` | 被踢出房间 |

## 4. Socket.io 事件流

### 4.1 用户加入房间

```
客户端                    服务器                    其他客户端
  │                         │                          │
  │──── join-room ─────────>│                          │
  │                         │──── online-members ─────>│
  │<─── online-members ─────│<─── online-members ─────│
```

### 4.2 发送消息

```
客户端                    服务器                    其他客户端
  │                         │                          │
  │──── send-message ──────>│                          │
  │                         │──── new message ───────>│
  │<─── ACK ────────────────│                          │
```

### 4.3 阅后即焚

```
客户端A                  服务器                    客户端B
  │                         │                          │
  │(发送阅后即焚消息)         │                          │
  │──── send-message ──────>│──── new message ───────>│
  │                         │                          │
  │                         │       (10秒后)            │
  │                         │<─── message-burned ─────│
  │<─── message-burned ─────│                          │
```

## 5. 安全机制

### 5.1 敏感词过滤
- 配置文件: `config/sensitive-words.json`
- 发送消息前过滤敏感词
- 支持自定义敏感词列表

### 5.2 用户权限
- 房间创建者拥有管理权限
- 普通用户只能发送消息
- 禁言用户不能发送消息

### 5.3 输入验证
- 文件类型验证
- 文件大小限制
- 消息内容长度限制

## 7. 错误处理

### 7.1 HTTP 状态码

| 状态码 | 描述 |
|--------|------|
| 200 | 成功 |
| 400 | 请求参数错误 |
| 404 | 资源不存在 |
| 500 | 服务器内部错误 |

### 7.2 Socket.io 错误

- `user-writting` / `user-stop-writting` 失败时返回 `{success: false}`
- `send-message` 失败时返回 `{success: false, message: "错误信息"}`

### 7.3 前端错误处理

- `$http` 请求使用 `.then()` 和 `.catch()` 处理
- Socket 事件使用回调函数处理响应
- 错误信息显示在聊天区域顶部
